Entry for make.fun bounty **The GPS Swears It Was a Shortcut** ($2 pool): the GPS's one-line excuse, in its own voice, for sending the driver down the wrong road, judged pairwise by an AI judge.

`main.py` (Python 3, standard library only) writes one excuse to `/output/entry.txt`:

> The map swore the lake had a bridge, so I took its word for it, and frankly the ducks looked more confident in my routing than you do right now.

The excuse is a fixed string: no randomness, no network, no model calls, so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
